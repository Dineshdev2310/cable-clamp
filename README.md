# Cable Management Clamp

## Overview
This project is a 3D cable management clamp designed in Fusion 360. It helps organize multiple cables neatly under a desk or workstation,
reducing clutter and improving workspace organization.

## Features
- Designed using Fusion 360
- Holds multiple cables securely
- Compact and simple design
- Easy to install
- Suitable for home and office desks

## Software Used
- Fusion 360

## Project Files
- `cable management clamp.f3d` – Fusion 360 design file

## Applications
- Home office
- Computer desk
- Gaming setup
- Study table
- Office workspace

## Future Improvements
- Support for different cable sizes
- Multiple mounting options
- Improved durability
- 3D printable optimized version
